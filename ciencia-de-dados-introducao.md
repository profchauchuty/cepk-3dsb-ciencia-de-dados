# 🧪 O que é Ciência de Dados? (Data Science)

Ciência de Dados é uma área interdisciplinar que utiliza **métodos científicos, processos, algoritmos e sistemas** para extrair conhecimento e insights de dados estruturados e não estruturados. 

Imagine-a como o cruzamento entre a **Matemática/Estatística**, a **Ciência da Computação** e o **Conhecimento de Negócio**.

---

## 🏛️ 1. A Base: Onde os Dados Vivem (Bancos de Dados)
Antes de qualquer ciência, precisamos de matéria-prima. Os dados ficam armazenados em:

*   **SQL (Relacional):** Tabelas rígidas, como planilhas interconectadas. Ótimo para transações seguras (ex: extratos bancários).
*   **NoSQL (Não-Relacional):** Armazena dados de forma flexível (documentos, imagens, textos). Ideal para redes sociais e Big Data.
*   **Pipeline de ETL:** O processo de **E**xtrair, **T**ransformar e **L**impar os dados antes da análise. Dados sujos geram resultados errados.

---

## 🛠️ 2. Os 4 Pilares da Análise (A Jornada do Conhecimento)

A Ciência de Dados transforma dados em decisões através destes quatro níveis:

### 📊 A. Análise Descritiva ("O que aconteceu?")
*   **Foco:** Olhar para o passado e resumir o cenário.
*   **Exemplo:** Um relatório de vendas mostra que a empresa vendeu 500 unidades do "Produto X" no verão.
*   **Ferramentas:** Gráficos, médias, dashboards (Power BI/Tableau).

### 🔍 B. Análise Diagnóstica ("Por que aconteceu?")
*   **Foco:** Descobrir a causa raiz e correlações.
*   **Exemplo:** O cientista cruza os dados e descobre que as vendas do "Produto X" subiram porque a temperatura média foi 3°C maior que no ano passado.
*   **Ferramentas:** Filtros avançados, análise de correlação estatística.

### 🔮 C. Análise Preditiva ("O que vai acontecer?")
*   **Foco:** Prever tendências futuras usando modelos matemáticos.
*   **Exemplo:** Com base no histórico de clima e vendas, o modelo prevê que, se o próximo verão for quente, a demanda será de 750 unidades.
*   **Ferramentas:** Machine Learning, Regressões, Redes Neurais.

### 🚀 D. Análise Prescritiva ("O que devemos fazer?")
*   **Foco:** Recomendar a melhor ação para aproveitar a previsão.
*   **Exemplo:** O sistema sugere: "Compre o estoque de 750 unidades agora em junho para obter 15% de desconto com o fornecedor e garantir a margem de lucro".
*   **Ferramentas:** Algoritmos de otimização e simulação.

---

## 🔄 3. O Ciclo de Vida de um Projeto de Ciência de Dados

1.  **Entendimento do Negócio:** Qual problema queremos resolver?
2.  **Coleta de Dados:** Buscar os dados nos bancos (SQL/NoSQL).
3.  **Limpeza/Tratamento:** Remover erros, duplicatas e dados nulos.
4.  **Exploração (EDA):** Entender o comportamento dos dados com estatística.
5.  **Modelagem:** Treinar algoritmos de Inteligência Artificial.
6.  **Avaliação:** O modelo é preciso? Ele acerta as previsões?
7.  **Implantação (Deployment):** Colocar a solução em produção para o usuário final.

---

## 💡 Exemplo Prático: Netflix
*   **Banco de Dados:** Registra cada segundo do que você assiste, o que clica e o que ignora.
*   **Descritiva:** Mostra para a Netflix quais filmes são os "Top 10" do dia.
*   **Diagnóstica:** Entende que você gosta de "Suspense" porque sempre assiste até o final.
*   **Preditiva:** Prevê que há 95% de chance de você gostar da nova série que estreou hoje.
*   **Prescritiva:** Coloca essa série na sua tela inicial em destaque para garantir que você continue pagando a assinatura.
